RVV 向量引擎RVV vector engine

標準 RISC-V 向量擴充Standard RISC-V vector extension

依標準 RVV Zve32x 實作的整數向量單元，處理逐元素運算：activation、bias、requantize 與 pooling。因為是標準 ISA，現有的編譯器與函式庫可以直接使用。 An integer vector unit built to standard RVV Zve32x. It handles element-wise work: activation, bias, requantize and pooling. Because it is standard ISA, existing compilers and libraries work as they are.

  • Zve32x，整數全指令, full integer set

我們怎麼驗證How we verify

正確與否由比對結果決定，而不是「看起來對」或 lint 通過。 Correctness is decided by comparison results, not by “looks right” or a clean lint.

逐 commit 與 Spike 比對Per-commit lockstep with Spike

RTL 每一筆 commit 的結果都與 Spike ISS 對照，向量 CSR 也在比對範圍內。Every commit the RTL retires is compared against the Spike ISS, vector CSRs included.

逐位元的 golden 資料Bit-accurate golden data

矩陣運算對照 NumPy golden，推論結果對照 TFLM。換傳輸路徑不能改變任何一個位元組。Matrix math is checked against a NumPy golden and inference against TFLM. Changing the transport path may not change a single byte.

一行指令重跑Re-run with one command

核心流程只用開源工具：Verilator、Spike 與 RISC-V GCC。沒有執行過的 gate 不會標成通過。The core flow uses only open-source tools: Verilator, Spike and RISC-V GCC. A gate that has not run is never marked as passed.
