Magpie SoC Roadmap

Magpie 系列有四條 IP 產品線：嵌入式 CPU、Linux 應用處理器、邊緣 AI NPU 與外部記憶體控制器。它們最後匯集成同一個目標：車用 SoC ASIC。 The Magpie family has four IP lines: embedded CPU, Linux application processor, edge AI NPU and external memory controller. They converge on one target: an automotive SoC ASIC.

各項狀態為 2026 年 7 月的進度。 Status as of July 2026.

車用 SoC ASICAutomotive SoC ASIC

四條產品線整合成一顆晶片：應用處理器跑 Linux，NPU 負責推論，控制核心處理即時工作，DDR 控制器供應權重頻寬。 The four lines integrate into one chip: the application processor runs Linux, the NPU handles inference, the control core handles real-time work, and the DDR controller supplies weight bandwidth.

  • Magpie M6Linux 應用處理器Linux application processor
  • Magpie M3VNPU 推論NPU inference
  • Magpie M1A即時控制核心Real-time control core
  • Magpie DDRDDR4 記憶體控制器DDR4 memory controller
